# Nomad Code — сборки

Готовые сборки Nomad Code для обновления приложений. Код — в отдельном закрытом репозитории.

- Выпуск **`dev`** — последняя сборка: `phone-update.apk.gz` (приложение для Android, gzip) и
  `phone-update.json` (`sha` — SHA-256 APK, `size`, `built` — время сборки, мс). Телефон
  проверяет его сам и ставит новую версию.
